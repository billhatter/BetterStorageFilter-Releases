# Changelog

## 0.2.0 — beta

- Independent ON/OFF type and weight filters, with five types above four weights.
- Reset Filters replaces All and enables every toggle; default is all ON.
- Empty rows show no matches, and runtime-session selections are retained.
- Restores original native filter flags together with radio state when releasing UI ownership.
- Preserves inactive Storage construction handling, virtualization and the provider-owned IRTweaks Alt workflow.

The ZIP is the same authenticated 0.2.0 artifact installed for QA; publication does not rebuild it. No vanilla edition or game/dependency DLLs are included.
